## 🎯 核心特性

### 瀑布流布局
```
固定列数：4列（桌面）/ 3列（平板）/ 2列（手机横屏）/ 1列（手机竖屏）
动态高度：根据卡片类型和内容自动计算
紧密排列：不同高度卡片紧贴，无空隙
Y轴滚动：容器固定高度，内容可滚动
```

### 卡片高度计算
```typescript
基础高度: 420px
描述超过30字: +30px
标签超过2个: +40px
有作者信息: +60px
视频类型: +50px（时长徽章）
攻略类型: +150px（亮点、最佳时间）
摄影师类型: +100px（擅长领域、统计数据）
```

### 虚拟滚动
- 仅渲染可见区域卡片
- DOM节点减少 90%+
- 滚动流畅度 60fps

---

## 🚀 性能优化

1. **虚拟滚动**: 仅渲染可见区域，大幅减少DOM节点
2. **懒加载**: 所有图片 `loading="lazy"`
3. **动态高度**: 预计算卡片高度，避免重排
4. **响应式列数**: 根据屏幕宽度自动调整
5. **事件优化**: 按钮事件冒泡到父组件统一处理
