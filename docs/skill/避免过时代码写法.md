## TypeScript

### 禁用
- `var` —— 用 `const` / `let`
- `namespace` / `module` 关键字 —— 用 ES Module
- 滥用 `enum` —— 用 union 字面量类型或 `as const` 对象
- `any` —— 用 `unknown` + 类型守卫
- `// @ts-ignore` —— 用 `// @ts-expect-error`（能捕获"不再出错"的过时注释）
- `require()` —— 用 ESM `import`
- 旧装饰器语法（`experimentalDecorators`）—— 项目未启用，不要引入

### 推荐
- `import type` 区分类型与值（避免循环依赖与运行时副作用）
- `satisfies` 运算符做类型校验保留推断
- `as const` 做字面量推断
- 函数式组合优于 class 继承

---

## CSS / SCSS

### 禁用（Sass 已弃用，dart-sass 会告警/报错）
- `@import` —— 改 `@use` / `@forward`
- `lighten()` / `darken()` / `saturate()` / `desaturate()` 等全局颜色函数 —— 改 `@use 'sass:color'` + `color.adjust($c, $lightness: 8%)`
- `/` 做除法 —— 改 `@use 'sass:math'` + `math.div($a, $b)`

### 禁用（布局/写法）
- 浮动布局（`float: left/right`）—— 用 flex / grid
- `<table>` 布局
- 冗余 `-webkit-` / `-moz-` 前缀 —— browserslist 已排除 IE，新特性按需用 `@supports`
- `!important` 滥用
- 行内 `style="..."` 写死样式（除动态绑定）

### 推荐
- `@use` 命名空间收敛变量
- CSS 自定义属性 `--var` 做主题切换
- `:deep()` 在 scoped 透传（项目已用）
- `clamp()` / `min()` / `max()` 做响应式
- `inset` 简写、:is()` / `:where()` 选择器
- `gap` 替代 margin 间距

---

## HTML

### 禁用
- 废弃标签：`<center>` / `<font>` / `<marquee>` / `<frame>` / `<frameset>`
- 表现属性：`align="..."` / `bgcolor="..."` / `border="..."`（用 CSS）
- 内联事件：`onclick="..."` / `javascript:` 协议（用 Vue `@click`）
- `<table>` 做布局
- `target="_blank"` 不带 `rel="noopener noreferrer"`

### 推荐
- 语义化标签：`<nav>` / `<main>` / `<article>` / `<section>` / `<aside>` / `<header>` / `<footer>`
- `aria-*` 做无障碍（项目已用 `aria-hidden`）
- `<picture>` + `srcset` 做响应式图片
- `<img>` 必带 `alt`（装饰性用 `alt=""`）

## 项目内已知待迁移点

> 维护时若遇到，顺手改掉。

1. **`src/pages/Aphorism/components/CategoryNav/index.scss`**（及 `_backup_scheme1_bamboo/index.scss`、`Aphorism/index.scss` 的 `mode-tabs-vertical` 段）
   仍用了 `lighten($wood-light, 8%)`。Sass 已弃用，应迁移为：
   ```scss
   @use 'sass:color';
   // ...
   color.adjust($wood-light, $lightness: 8%)
   ```
   注意：`@use` 必须在文件顶部，不能在嵌套块内；迁移时把颜色变量抽到顶层 `@use` 之后。

2. **SCSS 变量全局重复定义**
   `CategoryNav/index.scss` 顶部与 `Aphorism/index.scss` 的 `mode-tabs-vertical` 段各自声明同名变量（`$gold-light` 等）。长期可收敛到 `@use` 命名空间，避免命名污染。
