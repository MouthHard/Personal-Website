# 常见 Bug 模式总结

> 从项目实际 bug 中提炼的易犯错误清单，每类给出症状、根因模式和预防措施。
> 日期：2026-11-02 整理

---

## 一、SCSS 嵌套与大括号问题（高频）

**出现次数**：3 次（2026-10-30、2026-10-31、2026-11-02）

| 症状 | 根因模式 |
|------|----------|
| 弹窗渲染但不可见 | 选择器被意外嵌套在父块内，scoped 编译后选择器不匹配 |
| 构建报 `unmatched "}"` | 闭合括号位置错误 / edit 替换时缩进错乱导致多出 `}` |

**预防**：
- SCSS 嵌套不超过 4 层，闭合括号紧跟对应选择器
- `edit` 替换样式块前先 `read` 确认实际缩进，`oldString` 每行缩进须严格一致
- 构建失败时用 `npx sass <file> --no-source-map` 单独编译定位行号
- 新增样式块后立即构建验证

---

## 二、lint-staged / Git 钩子陷阱（高频）

**出现次数**：3 次（2026-10-30、2026-10-31 ×2）

| 症状 | 根因模式 |
|------|----------|
| 提交后 235 文件丢失 | lint-staged stash 机制冲突，stash pop 失败 |
| 大量文件处理时 SIGKILL | lint-staged 一次性处理过多文件，内存/超时溢出 |
| 提交被 pre-commit 拦截 | eslint/stylelint 规则与项目代码冲突 |

**预防**：
- 大批量改动时分批 `git add` + `git commit`，避免 lint-staged 一次处理过多文件
- 钩子失败时看终端输出，手动修复后重新提交，不要 `--no-verify` 跳过
- stylelint 规则须与项目既有代码风格匹配，冲突时调整规则而非逐个豁免

## 三、路径与构建配置

**出现次数**：1 次（2026-10-30）

| 症状 | 根因模式 |
|------|----------|
| 部署后图片 404 | Vite `base` 路径与实际部署路径不一致 |

**预防**：
- 部署到子路径时确认 `vite.config` 的 `base` 与部署路径匹配
- 资源引用用相对路径或 `import` 方式，避免硬编码绝对路径

---

## 四、资源加载性能

**出现次数**：1 次（2026-10-30）

| 症状 | 根因模式 |
|------|----------|
| 过渡图加载慢导致空白 | 远程图片未本地化 / 体积过大 / 未懒加载 |

**预防**：
- 大图本地化并转 AVIF/WebP 格式（项目已有 AVIF 迁移记录）
- `<img>` 加 `loading="lazy"`，首屏外的图片延迟加载
- 过渡动画用 CSS 而非图片，减少网络请求

## 快速自查清单

每次提交前过一遍：

- [ ] SCSS：新增/编辑的样式块是否构建通过？
- [ ] Git：`git add` 的文件数量是否合理（避免一次提交数百文件）？
- [ ] 路径：新增的资源引用路径是否正确？
- [ ] 性能：新增图片是否懒加载 + 合理格式？
