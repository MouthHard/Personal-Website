# 过渡图加载慢导致空白

> 日期：2026-10-30
> 模块：PageChange 过渡组件

---

## 症状

页面切换时过渡帘幕出现，但 4 块中图片空白（只有渐变底色），图片加载极慢。

## 根因

**图片太大**：每张 1-2MB（最大 2MB），20 张共 24MB。
- 预加载 20 张占满浏览器 6 个并发连接
- 过渡 4 张图排队等待，过渡动画 1.6 秒结束前图片未加载完
- OSS 无 `Cache-Control` 头，浏览器缓存不可靠

## 排查过程

1. 方案 A（远程预加载）失败 → 图片太大来不及完成
2. 本地化后仍慢 → 1-2MB/张本地也慢
3. 测量 dev server：单张 0.21 秒，但 20 张预加载占满并发
4. 检查 OSS HTTP 头：无 Cache-Control、Content-Disposition: attachment
5. 根因确认：图片体积过大是核心问题

## 方案对比

| 方案 | 做法 | 结果 |
|------|------|------|
| 远程预加载 | requestIdleCallback 预加载 | ❌ 24MB 来不及 |
| 本地化 | 下载到 public/ | ⚠️ 消除网络问题但图片仍大 |
| **本地化 + 压缩** ⭐ | sharp 压缩到 1920×1080 | ✅ 23MB → 6MB |
| **本地化 + AVIF** ⭐⭐ | 转 AVIF q60 | ✅ 6MB → 4.6MB |

## 最终方案

1. 下载 20 张图到 `public/change/`
2. 用 sharp 压缩：`resize(1920, 1080).avif({ quality: 60 })`
3. 23MB → 4.6MB，4 张过渡仅 1.4MB
4. `requestIdleCallback` 预加载到缓存

## 验证

- 4 张过渡 1.4MB，本地加载 < 0.3 秒 ✓
- 过渡动画 1.6 秒内图片完整显示 ✓

## 预防

- 过渡/加载动画的图片必须随应用本地分发，不依赖远程 CDN
- 图片体积控制：过渡图 < 300KB/张，画廊大图 < 500KB/张
- 优先使用 AVIF 格式（比 WebP 小 20-30%）
- 预加载不要超过浏览器并发限制（6 个），大图分批加载
