## 详细分析与解决方案

### 冲突 1: lint-staged stash 陷阱

**详见**：`git/2026-10-31-lint-staged-stash陷阱导致235文件丢失.md`

**配置文件**：`.lintstagedrc.json`
```json
{
  "*.{vue,ts,js}": ["eslint --fix", "prettier --write"],
  "*.{css,scss}": ["stylelint --fix", "prettier --write"]
}
```

**问题**：`--fix` 修改文件 → stash pop 冲突 → 改动丢失

**解决方案**：
1. 提交前必须 `git add -A`（消除未暂存改动）
2. 提交后必须 `git stash list` + `git diff HEAD`（验证无丢失）
3. 如有残留 stash，立即 `git stash pop` 解决

---

### 冲突 2: stylelint 规则与项目代码

**详见**：`css/2026-10-31-stylelint规则与项目代码冲突.md`

**配置文件**：`stylelint.config.cjs`
```js
module.exports = {
  extends: ['stylelint-config-standard-scss'],
  rules: {
    'scss/at-rule-no-unknown': [true, { ignoreAtRules: ['use', 'forward', 'tailwind'] }],
    'selector-class-pattern': null,
    'no-descending-specificity': null,
  },
};
```

**问题规则**：
| 规则 | 要求 | 项目实际 | 建议配置 |
|------|------|----------|----------|
| `keyframes-name-pattern` | kebab-case | camelCase | `null`（关闭） |
| `declaration-block-single-line-max-declarations` | 1 | 多声明单行 | `null`（关闭） |
| `selector-pseudo-class-no-unknown` | 标准 CSS | Vue `:deep` | `ignorePseudoClasses: ['deep']` |
| `font-family-no-missing-generic-family-keyword` | 必须有 generic | 缺少 | 按需修复 |

**解决方案**：更新 `stylelint.config.cjs`：
```js
rules: {
  'scss/at-rule-no-unknown': [true, { ignoreAtRules: ['use', 'forward', 'tailwind'] }],
  'selector-class-pattern': null,
  'no-descending-specificity': null,
  'keyframes-name-pattern': null,
  'declaration-block-single-line-max-declarations': null,
  'selector-pseudo-class-no-unknown': [true, {
    ignorePseudoClasses: ['deep', 'global']
  }],
}
```

### 冲突 3: lint-staged SIGKILL

**详见**：`git/2026-10-31-lint-staged大量文件SIGKILL.md`

**解决方案**：在 `.husky/pre-commit` 中增加内存：
```bash
export NODE_OPTIONS="--max-old-space-size=4096"
npx lint-staged
```

### 冲突 4: @typescript-eslint 版本

**当前版本**：
- eslint: `^8.57.0`
- @typescript-eslint/eslint-plugin: `^5.62.0`
- @typescript-eslint/parser: `^5.62.0`
- typescript: `^5.9.3`

**问题**：@typescript-eslint v5 官方支持到 TypeScript 5.0。TS 5.9 的新语法可能不被识别。

**解决方案**：升级到 @typescript-eslint v6+（需要 ESLint 8.57+，已满足）：
```bash
npm install -D @typescript-eslint/eslint-plugin@^6 @typescript-eslint/parser@^6
```

**风险**：v6 有 breaking changes，需要测试 lint 结果。

### 冲突 5: public/test/ 反复提交

**问题**：`.gitignore` 中有 `public/test/`，但 `git add -A` 仍会添加已跟踪文件。

**根因**：.gitignore 只对未跟踪文件生效。一旦文件被 git 跟踪，.gitignore 无法使其被忽略。

**解决方案**：
```bash
git rm -r --cached public/test/    # 解除跟踪（保留本地文件）
git commit -m "chore: 移除public/test的git跟踪"
```

**预防**：提交前用 `git add --dry-run .` 检查，确认无 `public/test/` 文件。

---

### 冲突 6: stylelint 不认识 :deep

**问题**：Vue 3 scoped CSS 的 `:deep()` 伪类被 stylelint 报为 unknown。

**解决方案**：在 stylelint.config.cjs 中配置：
```js
'selector-pseudo-class-no-unknown': [true, {
  ignorePseudoClasses: ['deep', 'global']
}]
```
