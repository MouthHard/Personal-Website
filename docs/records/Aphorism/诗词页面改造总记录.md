## 2. 分类导航与模式 tab

### 2.1 定稿：竹简卷轴

需求是把分类容器与内部选项做成现实中的诗词/书籍物品，强调 3D 拟物质感；共构思六种方案，最终选择**方案一·竹简卷轴**：

| # | 方案 | 状态 |
|---|------|------|
| 一 | 竹简卷轴（木轴 + 韦编 + 竹简 + 丝带） | ✅ 定稿 |
| 二 | 线装古籍版框 | 试看，未采用 |
| 三 | 藏书阁木架 | 试看，未采用 |
| 四 | 诗笺笺谱 | 试看，未采用 |
| 五 | 古籍函套 | 试看，未采用 |
| 六 | 朱砂印谱册 | 试看，未采用 |

关键结构：

- **左右木轴**：34px 宽木色纵向渐变 + 90° 高光暗影；`::before` 叠木纹；上下 `rod-cap`/`rod-ring` 做铜箍，中心 `rod-stud` 鎏金铆钉，`rod-label` 竖排“诗/卷”。
- **竹简展开区**：竹色纵向渐变 + 38px 间距竖线模拟并排竹简；上下 `bamboo-edge` 边框 + 内阴影做凹陷；`max-height` + 自定义木色滚动条。
- **韦编**：上下各一条 4px 黑绳，9 个 `cord-knot` 编结按 6%～94% 等距分布。
- **主分类竹简**：竹节横纹 + 竖向竹纹 + 竹色横向渐变三层背景；`tab-hole` 穿编孔、`tab-grain` 侧光、`tab-icon` 分类图标、`tab-name` 楷体墨字、`tab-glow` 横扫高光。
- **子分类竹简**：与主分类同构，尺寸缩小。
- **中分丝带**：两端朱砂流苏球 + 3px 朱砂/鎏金渐变丝带。
- **左侧模式 tab**：竹席底纹 + 上下韦编黑线；竹简 tab 同样三层背景。

### 2.2 后续微调（2026-11-19）

- **竖直压缩**：减小 `scroll-content` padding、`category-tabs` margin/padding、tab 最小高度、divider 间距、grid padding、item 最小高度；分类区总高约 240 → 170px，24px/18px 字号不变。
- **韦编贴边**：修正模板类名 `cord-top`/`cord-bottom` 与 SCSS `.cord.top` 的失配，改为 `&.cord-top`/`&.cord-bottom`，杆体贴到书卷上边框。
- **竹节孔四角化**：每枚竹简从“上下居中两孔”改为“四角各一孔”（left/right × top/bottom）；active 金色孔高亮。
- **移除 active 朱砂点**：删除右上角 `tab-seal`/`item-seal` 及对应样式，避免与四角孔重复。
- **模式 tab hover**：保留竹牍/朱漆原本的多层内高光、暗底与下缘台阶；自然态用金色呼吸描边，active 改用朱红描边 + `tabRingPulseRed`，不再用金色光。
- **图标选择器**：图标组件不透传 `class`，样式统一用 `> svg` 直接选中，避免 `.tab-icon` 成为死代码。

### 2.3 踩坑

- SCSS 变量 `$` 后不能有空格，否则会被解析成选择器。
- 大段替换 SCSS 后必须编译验证；括号失衡在 Sass 阶段才会暴露。
- 装饰伪元素统一 `pointer-events: none`，避免拦截分类/按钮点击。
- 曾尝试 `conic-gradient + mask-composite: exclude` 做旋转描边，浏览器会把整层挖空；最终改为实心描边 + 呼吸辉光。

## 3. 架构审查与分级优化（2026-11-17）

审查范围：主组件 + 8 个子组件 + 2 个 store + service / 工具 / 类型 / 数据源。按“风险 × 收益 × 回归面”分四级落地：

| 级别 | 定位 | 主要内容 |
|------|------|----------|
| P0 | 功能正确性 | 最近浏览主流程失效、复制失败仍提示成功、`typeLabel` 死代码 |
| P1 | 健壮性与安全 | `v-html` 手写转义、弹窗无键盘/焦点管理、搜索历史重复写入 |
| P2 | 架构与性能 | 交互逻辑三处重复、搜索索引构建两次、`limit=100` 隐性截断 |
| P3 | 规范与清理 | `:key=index`、`pageSize` 双处硬编码、死代码、`NaN` 未过滤 |

关键实现：

1. **最近浏览下沉到 `PoemModal`**：弹窗 `visible` 打开即记录，主页面与书房页两个入口自动覆盖；移除 StudyRoom 的重复显式调用。
2. **分享逻辑统一**：抽 `usePoemInteractions`，`navigator.clipboard`/`navigator.share` 均 `await + try/catch`，失败走 `share.error()`，用户取消分享不报错。
3. **DOMPurify 白名单**：赏析文本先转义文本元字符，再把 Markdown 加粗/换行转成受控标签，最后 `DOMPurify.sanitize(..., { ALLOWED_TAGS: ['strong','br'] })`。
4. **弹窗 a11y**：`role="dialog"` + `aria-modal`；Esc 关闭；Tab/Shift+Tab 焦点循环；打开记住触发元素并聚焦关闭按钮，关闭/卸载归还焦点。
5. **搜索历史单一出口**：`commitSearch(query)` 统一写历史 + emit 搜索，三处提交路径不再各写一次。
6. **共享搜索索引**：`usePoemSearchIndex` 复用 `categoryFilter` 的模块级索引，避免同一批数据构建两份全文串。
7. **去掉 `limit=100`**：store 改为 `limit: params.limit`，不传取全量，避免数据超过 100 首时静默丢数据。
8. **P3 清理**：稳定 `:key`、抽 `DEFAULT_PAGE_SIZE`/`PAGE_SIZE_OPTIONS`、删 `getPoem`、存储 ID 过滤 `NaN`。

验证：`vue-tsc` 从 5 条既有错误降到 4 条（删 `typeLabel` 后消除 1 条）；`vite build` 成功；浏览器验证弹窗焦点/Esc/body overflow、赏析加粗、搜索历史仅 1 条、最近浏览 `[43,44]` 无重复。

## 4. 过时与弃用代码清理（2026-11-17）

| 级别 | 内容 |
|------|------|
| P0 | `PoetIcon.vue` SVG path 被截断；`class`/`style` 被声明为 prop，拦截 attribute 透传，导致图标撑到约 1073px |
| P1 | `==` 松散比较、`as any`、`Promise<any>`、过时后端注释 |
| P2 | iconfont 冗余属性、空 `<script setup>`、`v-for :key=index`、`transition: all` |

关键处理：

- **PoetIcon**：换回完整 Lucide user 图标（`viewBox="0 0 24 24"` + path/circle），移除 `class`/`style` props，恢复 class 自动透传。
- **类型安全**：`services/aphorism.ts` 用 `PoemFilterKey` 白名单 + `toPoemFilterKey()` 收窄；`categoryId` 用结构类型收窄；排序值只允许 number/string 参与比较。`static-data.ts` 的 `Promise<any>` → `Promise<unknown>`，泛型约束 `Record<string, any>` → `object`。
- **数据源注释**：`poem.ts` 中“后端 API”描述改为本地静态 JSON，并保留未来平滑迁移说明。
- **iconfont 清理**：实际只有 `BackIcon`、`EmptyIcon`、`EmptyPoemIcon`、`CompassIcon` 4 个含 `t`/`p-id`/`version`/空 `fill` 等冗余属性；正则要求属性前有空白，避免误伤 `height`。
- **空脚本**：删除 8 个真正空的 `<script setup>`；纯 `<template>` SFC 合法。
- **稳定 key**：PoemCard 诗句行用 `line-${index}-${line}`；StudyRoom 诗人/足迹用名称。
- **`transition: all` 51 处**：改为显式 `transition-property`，属性集 = 视觉安全集（transform/opacity/box-shadow/color/background/background-color/border-color/filter/text-shadow）∪ 元素实际属性，避免几何属性引发布局抖动。

验证：4 个 SCSS 全部通过；`transition: all` 残留 0；iconfont 冗余属性 0；空脚本 0；浏览器首页/书房 0 console error。

### 5.4 发现区重组与 query 地基

- 新增 `filterByCategoryName(groupId, subName)`（按名称直滤，不依赖 categories 加载时序）与 `filterByAuthor(author)`（精确过滤，避免全文搜索混入“内容提到该诗人”的作品）。

- 列表页 `applyQueryFilters()` 支持 `search` / `author` / `dynasty|subject|emotion|school|form|usage`，挂在 `onMounted` + `onActivated`（KeepAlive 恢复）+ `watch(route.query)` 三个时机。

## 11. 工程经验

- **CSS 拆分等价性**：PoemModal 2114 行、StudyRoom 2108 行拆分后，编译 CSS 规范化逐行 diff 零差异；partial 内原样拷贝 + 外层补完整父链即可保证选择器等价。
- **Sass 编译验证**：只用 `npx sass --no-source-map <file>.scss` 输出 stdout；Windows Git Bash 下把 `/dev/null` 作为 sass 输出目标会生成保留设备名 `nul` 垃圾文件。
- **npm 缓存权限**：默认缓存目录无写权限时 `EPERM`，安装前把 `npm_config_cache` 指向系统 Temp 下的临时目录，用完删除。
- **图标 class 不透传**：本项目图标组件不声明 class prop，样式直接选 `> svg`。
- **mask 陷阱**：`mask-composite: exclude` 在目标浏览器可能把整层挖空；描边优先用实心 `border` + `box-shadow`。
- **Playwright**：默认会话在命令间不保持；涉及多次交互/刷新的验证用固定 `-s=<name>` 会话，截图与快照写到项目外临时目录，用完清理。
- **切片脚本**：统一使用 0-based 半开区间 `[a,b)`，避免 1-based 与 0-based 混用偏移一行。
- **CRLF**：大文件按行处理时保留原行尾，避免整文件 diff 噪声。
