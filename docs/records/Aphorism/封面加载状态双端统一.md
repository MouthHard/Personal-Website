# 封面加载状态双端统一

> 日期：2026-11-20
> 涉及文件：`src/composables/aphorism/usePoemBackground.ts`、`src/pages/Aphorism/components/PoemCard/index.vue`、`src/pages/Aphorism/components/PoemModal/index.vue`、`src/pages/Aphorism/components/PoemModal/styles/_scroll-base.scss`

---

## 背景

诗词卡片用 `<img>` 显示配图，弹窗用 CSS `background-image` 显示同一张配图（纸背透印）。两个问题：

1. **加载/失败图不一致**：卡片有 loading/error 占位图，弹窗没有——用户要求两处显示同一套占位图，且加载/重试成功后都要换回原图。
2. **弹窗纸背背景图**：用户希望弹窗左侧纸背用卡片的图片地址，但透明度要低，不能影响文字展示。

## 方案对比

| 方案 | 思路 | 结论 |
|------|------|------|
| A. 各自监听 | 卡片和弹窗各自维护加载状态 | ❌ 两处无法感知对方结果，卡片失败但弹窗成功时状态不一致 |
| B. 模块级共享状态表 | 用 composable 里的 `reactive(Map)` 记录每张图的加载状态，两处订阅 | ✅ 采用。任一处加载成功/失败，另一处立即同步 |

## 实现逻辑

### usePoemBackground.ts：封面状态机（复用现有 composable，未新建文件）

- `statusMap: reactive(Map<url, 'loading'|'loaded'|'failed'>)`：地址 → 最新状态。
- `useCoverStatus(source)`：响应式读取某地址的加载状态。
- `reportCoverLoaded/Failed()`：卡片 `<img>` 的 load/error 上报。
- `ensureCoverLoaded()`：给没有 `<img>` 的弹窗主动 `new Image()` 预加载。
- `coverRetrySrc(url, n)`：附加 `?_r=n` 绕开浏览器对失败请求的记忆，取到的仍是同一张图。
- 退避重试：`RETRY_DELAYS = [2s, 4s, 8s]`，最多 3 次，成功后清零计数。
- 导出 `loadingCover` / `errorCover` 占位插画，卡片与弹窗共用同一套图。

### PoemCard：原图常驻 + 占位叠层

**原 bug**：原来 `<img v-if="!imgFailed">` 在失败后被移除，换成 error 图，导致重试成功永远无法恢复原图。

**修复**：原图 `<img :src="imgSrc">` 常驻不移除；占位图作为叠层盖在上面，`locallyLoaded` 决定撤除。占位图地址由共享状态决定（`failed`→error 图，否则 loading 图）。当别处（弹窗）确认这张图能加载、但本卡片 `<img>` 还停在失败地址时，`watch(coverStatus)` 把 `imgSrc` 换成带重试参数的地址重新取图，成功后占位层自然撤掉。

### PoemModal：纸背透印同步占位

- `backdropUrl` 计算属性：共享状态 `loaded` → 用原图；`failed` → error 图；否则 loading 图。
- 加 `.is-placeholder` 类：占位态去掉 mask 与深色滤镜，避免插画被multiply抹掉。
- `<div class="paper-backdrop">` 用 `ensureCoverLoaded` 在 watch（immediate）里主动预加载。

### _scroll-base.scss：纸背透印视觉

```scss
filter: grayscale(0.85) sepia(0.4) contrast(0.85) brightness(0.95);
opacity: 26%;
mix-blend-mode: multiply;
mask-image: radial-gradient(ellipse 76% 68% at 50% 46%, rgb(0 0 0 / 40%) 0%, #000 100%);
```

**关键经验**：`multiply` 混合模式下**不能用 brightness 提亮**（会被抹平），要微压暗（0.95）才能让淡彩透出；中心用径向 mask 再淡一档（40%），保证标题与诗句所在中部清晰，图形只从四周透出。

## 踩坑记录

1. **原图失败后 `v-if` 移除导致无法复活**：改为原图常驻、占位叠层的结构，是这次最实质的 bug 修复。
2. **multiply + 提亮无效**：提亮在正片叠底下被抹平，改为微压暗 + 径向遮罩。
3. 占位图在 `is-placeholder` 态需 `mask-image: none`，否则彩色插画被中部遮罩吃掉。

## 验证结果

- 卡片与弹窗加载中/失败图一致，重试成功后两处都换回原图（截图佐证）。
- 纸背透印能透出配图轮廓且不夺正文文字。
- `typecheck` / `eslint` / `stylelint` / 33 项测试 / `npm run build` 全部通过。
