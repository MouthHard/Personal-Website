## 背景

站点是多子应用结构（诗词/音乐/博物馆等）。此前加载体验有三处各自为政：

1. **PageChange 帘幕**：原本只在导航超时后出现，用户觉得好看，希望「首次进入子应用必播完整动画」。
2. **加载/失败 UI**：帘幕里曾内置慢加载提示与失败卡，与用户「各子应用自己定制加载/失败 UI」的诉求冲突。
3. **ErrorBoundary**：只有一个 `error` 状态，靠 `message.includes('fetch'/'timeout')` 猜错误类型；`handleRetry` 只清状态，对 chunk 失败无效；且只包了 `router-view`，首页/路由 chunk 失败/异步回调错误都漏掉。

目标：**动画只负责「遮盖首次加载的空窗」，所有异常统一收口到 ErrorBoundary**，且软失败（超时/资源）与硬错误（代码/渲染）在视觉和纠错动作上彻底分开。

## 方案对比

### 播不播动画：按错误类型分流 vs 按屏幕有没有内容分流

| 方案 | 思路 | 结论 |
|------|------|------|
| A. 按错误类型 | 代码错误不播、资源错误播 | ❌ 误伤：chunk 首次失败是资源问题但屏幕空白；首页 setup 抛错是代码问题但也是空白 |
| B. 按屏幕内容 | 帘幕在挂→异常排队等播完；帘幕已收→异常立即生效 | ✅ 采用。是「唯一规则」，错误类型只是它的推论（代码错误九成发生在帘幕收起后，天然不播） |

### 动画时长期望

用户明确要求：合拢时间长、合拢后静止短、退场缓慢，且**上排抽走快、下排抽走慢**（阶梯异步），进场快以遮盖白屏。

| 阶段 | 时长 | 说明 |
|------|------|------|
| 进场滑入 | 800ms + 错峰 60×3 = 980ms | 四图合拢 |
| 合拢静止 | 320ms | 给「合拢」留一口气，不用于等加载 |
| 上排退场 | 600ms（延迟 0 / 40） | 抽走快 |
| 下排退场 | 900ms（延迟 280 / 320） | 抽走慢 |
| 合计 | 2520ms | `exitTotal()` = 320 + 900 = 1220ms |

原确认数字是 2s，后调为 2.5s。

### 是否改路由为 defineAsyncComponent

曾建议 `errorComponent = ErrorBoundary`，**最终撤回**：会把加载失败从导航期挪到挂载期，丢掉 vue-router 的导航取消能力，影响 keep-alive 匹配；且 ErrorBoundary 有了受控入口后，`router.onError` 可直接喂给它，无需组件先挂载。

## 实现逻辑

### 分层职责（关键设计）

- **PageChange**：只播 0→2.52s 纯动画，**完全不读加载状态**。
- **ErrorBoundary**：统一收口所有错误，按 `kind`(resource/runtime) 与 `mode`(fullscreen/region) 决定范围与按钮语义。
- **各子应用**：数据/图片空态与骨架自己定制（如诗词 `ErrorState` 管数据层、`usePoemBackground` 管封面）。

### 唯一规则：帘幕状态决定异常时机

`PageChange` 的 `handoff()` 是唯一出口：

```
帘幕在挂（inside/exit）→ 记下 pendingAction，等动画播完再交棒
帘幕已收（hidden）      → 立即 requestError，绝不重播动画
```

12s 导航等待（`WAIT_MS`）与退场计时互不干扰——这是踩坑里最隐蔽的一处。

### ErrorBoundary/channel.ts（唯一新增文件，107 行）

模块级单例发布订阅（`subscribeError` / `requestError`），因为 `router.onError`（组件树外）、`window` 事件、ErrorBoundary（组件树内）三者没有共同祖先可传 props。

- `ErrorPayload`：`kind`、`code`、`message`、`detail`、`stack`、`route`、`component`、`userAgent`、`scope`。
- 错误码集中常量 `ERROR_CODES`；软失败白名单 `SOFT_CODES = [ENTRY_TIMEOUT, CHUNK_LOAD]`。
- 10s 限次自动重载护栏 `shouldAutoReload()` + `reloadTo(path)`（hash 路由重载要保留路径）。只限制自动重载，用户点按钮不受限。

### ErrorBoundary/index.vue 改造

- 单一 `error` → `payload: ErrorPayload`，`show()/reset()` 通过 `defineExpose` 暴露，并可被 channel 驱动（受控模式）。
- 删掉三处 `message.includes()` 猜分类；`kind` 由来源决定，展示层只按 `mode` 分范围。
- 视觉调性由 `isSoft` 决定：软失败 = `SLOW LINK / WAITING` + 黄蓝色 +「这并不代表站点出错」；硬错误 = `SYSTEM FAULT / ALARM` + 红色警报条。
- 按钮语义：`resource` →「重新加载」（`reloadTo`）；`runtime` →「重新渲染」（`reset`）+ 次要「刷新页面」+「返回首页」。
- 新增 `mode="region"` 局部卡：`position: relative; min-height: 320px`，隐藏扫描线/诊断面板/返回首页等重型元素，宽 420px。用 `scope` 做订阅隔离——全局卡只收无 scope，局部卡只收自己的 scope。
- `onErrorCaptured` 对 `err` 归一化（Promise reject 可是任意值），带 `scope` 上报后 `return false` 不冒泡。
- z-index：帘幕 10000，错误页 10001。

### main.ts / App.vue

- `router.onError` 从「无条件 reload」改为只打印，**转交由 PageChange 统一 handoff**（保证动画播完再交棒，且带限次护栏）。
- `app.config.errorHandler` 兜底 `requestError`（覆盖 App.vue 自身出错）；`unhandledrejection` **只记日志不弹 UI**（避免插件脚本噪音）。
- `App.vue` 的 `ErrorBoundary` 从只包 `router-view` 扩到同时包 `#mainPage` + `#tabContainer`；**PageChange 与时钟留在外层**——否则帘幕会被错误态一起卸载，出现「帘幕消失后才弹错误页」的二次跳变。

### 诗词样板（三期）

`Aphorism/index.vue` 的 `poems-grid` 外包 `<ErrorBoundary mode="region" scope="aphorism-list">`。分工：原有 `ErrorState` 管数据加载失败，region 卡管组件渲染错误，两者不重复。

## 踩坑记录

1. **`navPending` 阻塞退场**：`maybeExit()` 里若等导航完成，慢加载时动画被无限拖长，违背「完整播一次」。修复：退场只看时间，与导航完成无关。
2. **`startExit()` 误清 12s 计时器**：导致超时永不触发。修复：12s 属于导航等待，与帘幕退场无关，不能在此清。
3. **内联 `animation-delay` 压制类规则**：四图退场的阶梯延迟若写在模板内联样式，会压过 SCSS `:nth-child` 的进场延迟。修复：移除内联，全部由 SCSS nth-child 控制；`exitTotal()` 从 `moveMs+180` 修正为实际最大 `320+900`，否则最后 320ms 被提前卸载截断。
4. **`message.includes('fetch')` 误判**：Chrome 的 chunk 报错含 `fetch`，会被判成网络错误。修复：按来源打 code，不猜字符串。
5. **chunk 失败 `handleRetry` 无效**：ESM module map 会缓存失败结果，必须 `location.reload()` 才能清。修复：`resource` 类走 `reloadTo`，带限次护栏防无限刷新。
6. **Vite dev 动态 import 模块实例不一致**：浏览器里注入错误时，`import('/src/.../channel.ts')` 拿到的是另一份实例、订阅收不到。必须从 `performance` resource entries 取带 `?t=` 时间戳的真实 URL。这是验证方法的坑，非功能问题。
7. **亮图上白字看不清**（旧版慢加载提示）：需加暗场渐变 scrim 托底（该提示现已删除，仅作经验留存）。

## 验证结果

真实浏览器模拟 7 类场景（截图画廊见会话临时产物，未入项目）：

| 场景 | 结果 |
|------|------|
| 首次进入 | 2.52s 完整演出：进场→合拢静止→上排快退/下排慢退→内容 |
| 二次进入 | `.page-change-overlay` 数量 = 0，不播 |
| 12s 超时 | `ERR_ENTRY_TIMEOUT` / SLOW LINK / soft=true /「重新加载」 |
| chunk 404 | 自动重载一次后 `ERR_CHUNK_LOAD` / SLOW LINK / soft=true，不无限刷新 |
| 运行时错误 | `SYSTEM FAULT` / ALARM / `ERR_COMPONENT_RENDER` / 三按钮 |
| 网络错误 | `LINK FAULT` / `ERR_NETWORK_ERROR` /「重新加载」 |
| 局部错误卡 | `region=true`、scope 隔离，竹简栏/分页保留，只替换列表区 |

静态校验：`typecheck` / `eslint` / `stylelint` / `sass` 编译 / 33 项测试 / `npm run build` 全部通过。
