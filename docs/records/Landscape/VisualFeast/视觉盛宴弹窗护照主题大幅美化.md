## 背景

方案六·旅行护照定稿后，用户要求大幅增强左右页及内部模块的视觉美术风格，不仅是微调阴影，而是大规模风格变换与装饰，且不影响文字展示。

## 改动内容

### 左页（签证页）新增装饰

| 元素 | 类名 | 说明 |
|------|------|------|
| 金属图钉 | `.vp-pin` | 左上角金色装订点，径向渐变+立体高光，增强"贴照"质感 |
| 手写 caption 条 | `.vp-caption` | 底部左下角，楷体地点 + 等宽日期，微倾斜 -1.5°，米白底金边 |
| 大号水印 | `.vp-watermark` | 居中斜置 `VISA №03`，淡棕色 4.5rem，护照页底层水印 |
| 签证有效期装饰条 | `.visa-footer` | 底部横向条 `VALID UNTIL 2027·10·31` + 倾斜绿色 `APPROVED ✓` 贴章 |
| 内层金线相框 | `.vp-frame` box-shadow | `inset 0 0 0 2px rgba(212,168,75,0.18)` 形成双层相框 |

### 右页（信息页）增强

| 元素 | 说明 |
|------|------|
| 信息字段色条 | 每行左侧 3px 色条：金色默认 / 蓝色 location / 紫色 remarks |
| 信息字段斑马纹 | 偶数行背景加深，表格可读性增强 |
| 签发官卡片色条 | 左侧金色色条，行标视觉锚点 |
| 签发验证区色条 | 左侧红色色条，与签发语义对应 |
| 页眉装饰星点 | 中间 `✦` 淡金色，页眉分隔装饰 |

### 此前轮次改动（同会话）

- sticky 按钮组贴底：`.page-right` padding-bottom 归零，消除固定时空隙
- 按钮组容器美化：暖金渐变底 + 烫金双线边框 + 立体光影
- 浏览 icon 补全：`sg-views` 补上 `EyeIcon`
- 印章大幅提亮：紫色 `#7b3fa0→#9b5fc8`，opacity 提升，三层 drop-shadow 含白色背光
- 更多探索模块重构：3列→2列 grid，明信片风格大卡（照片 190px + 底部渐变遮罩信息 + 倾斜胶囊印章角标）
- 签发官卡片精简：移除介绍行 `ac-title`，只保留姓名 + 数据
- REMARKS 合并到信息字段：新增 `if-row-remarks` 行，移除 DATE 行，删除原 `visa-remarks` 容器
