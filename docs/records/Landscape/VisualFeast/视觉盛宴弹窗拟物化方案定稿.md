## 背景

在 [取景器弹窗子组件提取](./取景器弹窗子组件提取.md) 基础上，用户要求为 `ViewfinderModal` 构思多种创意拟物化 UI 方案——模拟与现实摄影/风景/旅游相关的物品作为弹窗外观及内部部件。工作模式为"逐一试看轮换，满意即定稿"。

约束：
- 完全自由发挥布局和 UI 美术风格，不必参考现有或其他方案
- 弹窗及内部部件须立体美观，注重 3D 拟物质感（凹陷感、阴影层次、真实质感）
- 暗色系按钮，hover 比自然态略亮，active 用好看的渐变色系
- SVG 构造图形元素，PascalCase 命名
- 切换新方案不得基于上一方案惯性修改，须参考现实物品完全重新思考设计

## 实现逻辑（方案六·旅行护照）

整体为一本摊开的深蓝皮面护照，左页签证页展示图片与备注，右页信息页展示字段与互动数据，底部皮面桌垫承载翻页导航。

### 深蓝皮面封皮
- 深蓝渐变 `#1a3a5c → #0d2540 → #0a1a2e` + 45° 交叉细纹皮面纹理（双层 repeating-linear-gradient）
- 烫金底边光线（`#a87a1e → #e8c878 → #a87a1e` 渐变 + 发光阴影）
- 烫金国徽 SVG（双圈+五角星+中心点）
- PASSPORT（衬线体 0.5em 字距）+ 护　照（楷体）+ 编号 № CN-0001（等宽体）

### 摊开两页
- 米白纸张 `#f7f2e8 → #f0ead9` 渐变 + 水印网格纹理（双层 repeating-linear-gradient 28px 间距）+ 纸张暗角
- 中间书脊装订区：渐变阴影 + 竖向虚线缝线（双侧 dashed）
- 左页左侧内阴影 / 右页右侧内阴影（模拟书脊凹陷）

### 左页·签证页
- 页眉：VISA / 签证页—03—（衬线体+楷体，下边框分隔）
- 签证贴照：白边相框微倾斜 -1° + 图片降饱和 0.92 + 暗角内阴影
- 紫色钢印 SVG：圆形章 VISA·CHINA 2026，倾斜 -15°，opacity 0.85，油墨晕染感
- 矩形入境章：PORT OF ENTRY + 地点 + 日期，蓝色油墨倾斜 4°，半透明背景
- 手写备注区：虚线边框 + 楷体标题/作者（`STKaiti` 手写体）
- 签证标签：牛皮纸贴纸质感（`#e8dcc4 → #d8c8a8` 渐变 + 1px 边框）

### 右页·信息页
- 页眉：PARTICULARS / 信息页—04—
- 证件照：84×104 白边相框 + 四角 L 形定位标记 + 降饱和 0.7
- 信息字段：TITLE/LOCATION/DATE/CAMERA/AUTHOR 虚线分隔行
- 签证类别：左侧蓝色竖条 + VISA TYPE + 分类子项
- MRZ 机读码：两行 ICAO 标准等宽字体（`Courier New`），`<` 填充字符
- 验讫章互动数据：3×2 网格，虚线内框，激活态彩色发光（点赞蓝/喜爱红/收藏绿）

### 底部控制区（深蓝皮面桌垫）
- 深蓝渐变 + 皮面纹理
- 翻页导航：烫金边框按钮 PREV/NEXT（hover 发光，active 下压）
- 页码计数器：烫金边框 + 当前页金色 + 总页暗金

### 关闭按钮
- 烫金圆章（径向渐变 `#e8c878 → #d4a84b → #a87a1e`），hover 旋转 90° + 发光

## 踩坑记录

### ShareIcon 导入路径笔误
**问题**：重写模板时误将 `ShareIcon.vue` 写成 `ShareIconIcon.vue`。
**修复**：修正为 `@/pages/Landscape/icons/common/ShareIcon.vue`。

### MRZ 机读码中 `<` 字符处理
**问题**：MRZ 机读码中 ICAO 标准用 `<` 作填充字符，但 HTML 文本中 `<` 会被解析为标签开始。
**修复**：纯 HTML 文本位置用 `&lt;` 实体，`{{ }}` JS 表达式内用 `'<'` 字符串字面量（Vue 模板表达式内是 JS 语境，不会被解析为 HTML）。
