# 取景器弹窗子组件提取

> 日期：2026-10-30
> 涉及文件：`src/pages/Landscape/components/Home/components/VisualFeast/`

---

## 背景

用户要求在 VisualFeast（视觉盛宴）瀑布流中，点击图片后弹出一个有创意的图片详情弹窗，展示图片所有信息。UI 需参考现实里与图片/旅游/风景相关的物品。

## 方案对比

提供了 5 个创意方案供用户选择：

| 方案 | 概念 | 优点 | 缺点 |
|------|------|------|------|
| **单反相机取景器 HUD** ⭐ | 光学取景器+HUD参数 | 科技感强，信息密度高 | 元素多，实现复杂 |
| 旅行护照内页 | 签证盖章 | 旅行氛围 | 信息组织受限 |
| 博物馆展品画框 | 铭牌策展 | 优雅简洁 | 互动性弱 |
| 观景望远镜 | 单筒取景 | 沉浸感 | 信息展示空间小 |
| 旅行手账剪贴本 | 胶带贴纸 | 手作温暖 | 风格偏柔，不够酷 |

用户选择方案一（单反相机取景器 HUD），并要求逐一试看轮换。

## 实现逻辑

### 弹窗结构
- 金属顶板 + 品牌头 + FOCUS 绿灯
- 顶部 HUD 条：帧号/日期/分类/camera
- 左竖条 METERING：互动数据以 ISO/F2.8/1/250 等相机参数刻度呈现
- 中央取景框：图片 + 对焦框角标 + 三分线 + FOCUS 确认
- 右竖条 INFO：作者 + 标签 + 多维分类
- 底部 HUD 条：标题/地点/曝光补偿刻度盘
- 底部操作栏：导航拨盘 + 金属按键组

### 子组件提取
- `ViewfinderModal/index.vue`：弹窗模板 + script（props/emits 接口）
- `ViewfinderModal/index.scss`：弹窗样式（900 行）
- 父组件通过 `<ViewfinderModal>` 标签引用，传入 props 和监听 emits

### Props/Emits 接口
```
Props: visible, image, currentIndex, total, counts, liked, loved, favorited
Emits: close, navigate, like, love, favorite, share, download
```

## 踩坑记录

### SCSS 嵌套导致弹窗不可见
**问题**：原始 `index.scss` 中 `.masonry-grid` 的闭合括号在文件末尾的 `}}}` 中，导致 `.vf-modal` 被嵌套在 `.masonry-grid` 内。Vue scoped 编译后选择器变成 `.masonry-grid .vf-modal[data-v-xxx]`，但 DOM 中 `.vf-modal` 不在 `.masonry-grid` 内，样式不匹配——弹窗渲染但不可见。

**修复**：在 `.vf-modal` 之前显式闭合 `.masonry-grid`（加 `}`），末尾只保留 1 个 `}` 闭合 `.visual-feast-section`。

### 未使用的图标导入
**问题**：提取子组件后，父组件中 `ChevronLeftIcon`、`ChevronRightIcon` 不再使用，构建报错。

**修复**：删除这两个导入。
