# 视觉盛宴弹窗交互增强与跨类型推荐

> **日期**：2026-11-01
> **范围**：ViewfinderModal + VideoModal + 共享推荐组件 RelatedRecommend

---

## 背景

用户对 ViewfinderModal（护照隐喻弹窗）提出 5 个复合需求：
1. 6 个底部按钮继续加大加粗 icon 和文字
2. 作者、地点信息更明显
3. 补充作者关注功能
4. Store 状态同步检查
5. 跨类型推荐模块（先出方案再执行）

后续追加：
- 6 按钮 sticky 固定右页底部（滚动时始终可见）
- 去掉关闭按钮附近的 CN-00X 装饰

## 方案对比

### 需求 2+3：作者卡片 + 关注按钮

| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| A. props 驱动（父组件透传） | 与 ViewfinderModal 现有风格一致 | props 膨胀 | |
| B. Modal 内直接调 store | 简洁，GuideModal 有先例 | 风格略不同 | ✅ |

选择 B：Modal 内直接调 `dataStore.getPhotographer(authorId)` + `interactionStore.toggleFollowPhotographer(id)`。

### 需求 5：跨类型推荐策略

| 策略 | 信号强度 | 实现 |
|------|----------|------|
| 同作者其他类型作品 | 最强 | `getWorksByAuthor` 一行调用 |
| 同地点作品 | 次强 | 客户端过滤 |
| 相似 tags 跨类型 | 补充 | tags 交集匹配 |

优先级递减：同作者 > 同地点 > 相似 tags。UI：可折叠「探索更多」区，默认折叠。

### 推荐模块扩展范围

| 弹窗 | 适配性 | 决策 |
|------|--------|------|
| ViewfinderModal | 高 | ✅ P0 |

| GuideModal | 高 | ⏸ 后续 |

## 实现逻辑

### 1. 按钮加大加粗（SCSS）

`.sg-cell`：icon 22→26px，num 1.02→1.18rem，text 0.94→1.06rem，padding 7/8→9/10px，gap 6→8px，stroke 2.4→2.8。

### 2. 作者卡片（护照隐喻：签证官签章）

右页备注区上方新增 `.author-card`，通过 `image.authorId` 反查 `GlobalPhotographer`，展示头像+昵称+专长+统计+认证标+关注按钮。关注按钮三态拟物：虚线自然→烫金辉光 hover→烫金金属浮雕 following。

### 3. 地点强化

LOCATION 行加 `LocationIcon`（18px 蓝色），值高亮 `$ink-blue`。

### 4. Store 同步

**结论：架构已正确，无需改动。** 4 个 Modal 全部走同一个 `interactionStore`，新增关注按钮也走同一 store action，天然同步。

### 5. sticky 固定按钮

`.stamp-grid` 改 `position: sticky; bottom: 0; z-index: 5`，加不透明背景+顶部分隔线。

### 6. 去掉 CN-00X

删除 `.cover-no` 元素。

### 7. 跨类型推荐模块

**共享组件** `common/RelatedRecommend/`：
- props: currentId, currentType, authorId, location, tags, category, maxItems, theme
- 逻辑：同作者（`getWorksByAuthor`）> 同地点 > 相似 tags
- 两种主题：paper（护照米白）/ dark（CRT 暗色）
- UI：可折叠，横滑小卡片（缩略图+类型角标+标题+地点）

**集成**：
- ViewfinderModal：stamp-grid 上方，`theme="paper"`
- VideoModal：vhs-rack 下方，`theme="dark"`
- 点击推荐项 → 关闭弹窗 + `router.push` 跳转对应页面

## 踩坑记录

| 问题 | 根因 | 解决 |
|------|------|------|
| SCSS edit 提示 "modified since last read" | edit 后时间戳更新但 read 缓存未刷新 | 重新 read 后再 edit |
| `defineProps` 未赋值给变量 | 原代码无 `const props =` | 改为 `const props = defineProps<{...}>()` |
| `showMessage.follow` 签名确认 | 需验证 API | `message.ts:90-103` 确认 `success(name)` / `cancel(name)` |
